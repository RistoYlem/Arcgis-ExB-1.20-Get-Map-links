Ava url klikitud kohas/Map Link Opener

Kaardile klikkides avab vastava urli uues aknas ja kaardile klikidus asukohas, näiteks google street view või maaameti kaldfoto. Osad urlid on vaikimisi lisatud, aga neid saab ise ära võtta või juurde lisada.

Selleks, et vidinat kasutada tuleb see alla laadida ja salvestada oma serverisse (tegemist on juba compileeritud versiooniga). Windowsi puhul näiteks C:\inetpub\wwwroot kausta, seejärel tuleb vidin portalis registreerida järgida seda juhendit https://doc.arcgis.com/en/web-appbuilder/11.4/create-apps/add-custom-widgets.htm#ESRI_SECTION1_BBB45680A0204EFB8DB521977383EA8D
